# Earthquake Shake-Down

Earthquake Shake-Down is a Tkinter desktop app for assembling a small 2D building and testing it on a simulated earthquake shake table. It uses Pymunk for physics, NumPy for shake calculations, and Matplotlib for in-app visualization.

## Install

Install the required packages:

```powershell
python -m pip install -r requirements.txt
```

The packages are NumPy, Pymunk, Matplotlib, and pytest for validation.

## Start

```powershell
python app.py
```
